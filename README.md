# CodeAlpha Stock Portfolio Tracker

## About the Project

The Stock Portfolio Tracker is a Python-based application developed as part of my CodeAlpha Python Programming Internship.

The application allows users to view available stocks, select stocks, enter quantities, calculate individual investment values, view their portfolio, calculate total investment, and save portfolio information to a CSV file.

## Features

- View available stocks
- Enter stock symbols
- Accept lowercase and uppercase stock symbols
- Add stocks to portfolio
- Enter stock quantities
- Calculate investment value
- View portfolio
- Calculate total investment
- Save portfolio information to CSV
- Input validation
